# RoboRAG 本地研究工作台

在项目根目录运行，无需安装前端或 Python 第三方依赖：

```bash
python3 scripts/serve_research_progress.py
```

打开 <http://127.0.0.1:8794>。端口冲突可添加 `--port 8796`。
服务仅监听本机；前端不依赖 CDN，不会自动启动模型调用或机器人实验。

## 记录研究进度

- **研究总览**：当前推进、三条主线、完成任务数、待验证项、MCP 完整回合、阻塞与最近维护。优先展示进行中的任务，再按优先级、前置依赖和更新时间排序；点击当前任务即可检查验收标准。
- **研究路线**：列表 / 看板、搜索、主线和状态筛选；编辑研究内容、验收标准、负责人、日期、优先级、下一步、阻塞、依赖和证据。
- **实验台账**：一次任务执行对应一条记录。记录方法、评测协议、模型 / 推理强度、数据划分、布局 / 种子、经验库与代码版本、MCP server / 协议版本 / trace、成功、完成度、耗时与 token。
- **研究日志**：维护进展、决策、发现和阻塞；可关联研究任务。

点击任务名称即可编辑。保存后立即写入数据库；多页面同时编辑时，旧版本会收到冲突提示，保留输入，不覆盖较新数据。任务依赖不允许成环；被任务依赖或实验 / 日志关联的任务不能直接删除。删除前有确认，数据库维护历史保留变更前后快照。

首次启动从 `docs/research-progress.seed.json` 初始化 16 项研究任务与一条项目日志。预置任务依据现有仓库文档核查，已有基础但未通过完整效果验收的工作标为“待验证”。以后启动不重置用户的修改。

## 历史结果与指标

每次点击“刷新”都会重新读取以下三个来源，显示独立、只读的历史实验：

- `results/pilot-current.json`：7 条 pilot（包含一次中断）。
- `results/hexashell-consumption-20261023.json`：20 条正式公开布局叠衣复现。
- `results/roboicl-public-comparison-20261020.json`：9 条计划回合（5 条完成、1 条中断、3 条未运行）。

前端不改写这些原始文件。历史运行使用 HTTP / CLI，不能因为有工具调用就认作 MCP；HexaShell 复现未启用 RoboRAG 检索。新的 MCP 全链路结果需单独记录，MCP 完整回合必须填写 server、协议版本、trace 和结果证据。此检查验证记录完整性，不替代实际协议一致性测试。

选择“同条件分组”后查看表现，分组使用任务、场景、评测协议、模型、推理强度、数据划分、通信协议、库版本、代码版本和 MCP 配置；多种方法分别显示指标。记录者仍需核查预算、观测权限、布局 / 种子配对、并发及模型快照等条件。相同配置字段不自动证明因果收益、显著性或 SOTA。

- **成功率** = 已完成且明确成功的回合 / 已完成且有明确成功判定的回合，同时显示分母。
- **平均完成度**：只使用已完成且有原生评分的回合，归一到 0–100，单独显示样本数。
- **平均耗时**：有墙钟时间的完整回合均值，单位秒 / 分钟。它不是批次墙钟时间或纯执行延迟；检索和执行时间另存。
- **Token**：输入 + 输出。缓存输入属于输入子集；推理输出属于输出子集，不能再累加。两项齐全时自动计算总量；仅总量已知时可单独填写。
- **未知与中断**：缺失值显示 `—`，不会填零；不完整用量标为已知下限。中断不进入最终成功 / 完成度分母，但已有消耗保留在 token 合计中。
- **费用**：token 消耗不是货币账单，不生成虚构美元或人民币费用。

## 数据保存、导出与恢复

默认数据库：`data/research-progress.sqlite3`。SQLite 文件由现有 `.gitignore` 忽略，因此不会随普通 Git 提交上传。数据库和 JSON 备份包含用户记录，应自行保留副本。`--db` 可指定其他路径。

右上角“导出备份”下载 JSON：包含当前任务、手动实验、日志、最近维护摘要以及只读历史来源快照。实验页可导出 UTF-8 CSV；未知保持空值，潜在公式文本经过转义。完整变更前后快照保存在数据库 `activity` 表，JSON 备份只包含最近 60 条维护摘要，不是完整审计库备份。

恢复 JSON 到一个**新文件**，原数据库不会被覆盖：

```bash
python3 scripts/restore_research_progress.py /path/to/roborag-research-progress.json \
  --db data/research-progress-restored.sqlite3
python3 scripts/serve_research_progress.py --db data/research-progress-restored.sqlite3
```

恢复任务、手动实验与日志；历史来源仍从仓库文件读取，不把备份中的历史快照混入手动实验。更换数据库前停止原服务（Ctrl+C），或使用不同端口。备份不包含机器人视频、原始轨迹、原生结果文件；这些仍需保留在项目中。

## 验证

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -p 'test_research_progress.py' -v
node --test tests/test_research_progress_metrics.mjs
```

覆盖初始化和重启持久化、并发编辑冲突、依赖与关联、MCP 记录完整性、token 子集、未知 / 失败 / 中断口径、历史来源适配、JSON 恢复、CSV 导出、HTTP 写入边界与证据路径限制。浏览器交互验证使用独立临时数据库，不污染实际研究记录。
