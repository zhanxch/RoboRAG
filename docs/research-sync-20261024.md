## 当前里程碑

先在一个机器人任务上验证 **AI-friendly、cost-efficient、有效性**。当前为实测准备与接口实现阶段，尚无本轮 MCP 机器人回合成绩。SOTA 保留为后续研究目标，待单任务验证后扩展公平对照、消融、布局与种子。

目标流程：初始观察与目标 → 通过 MCP 检索历史经验 → GPT 生成当前任务的新 plan → 分块执行并在关键观察点返回回执 → 记录原生结果和完整消耗。持续会话保留稳定的工具定义、初始参考与计划前缀；缓存收益必须以实际缓存 token 日志判定。

## 已有基础与边界

- 经验库覆盖 4 个任务、9 张经验图、78 个阶段、312 个节点、303 条边；关联 567 个重叠的短动作窗口。
- 经验图描述已发生的示范，`next` 表示历史时间顺序；不等同当前场景的强制规划依赖。当前任务的 plan 和 action chunk 需由 GPT 结合当前观察生成。
- 库侧具备分字段检索、条件约束、来源追溯、按需动作证据与预算内上下文封装；本地检索本身不调用生成模型。
- 来源对话报告库侧 12 项测试通过，本次进度同步未重新运行这些测试。示例检索结果不是留出集效果、机器人成功率或端到端成本收益证明。
- MCP 接入、当前 plan 契约、分块执行与实测计量正在另一对话推进；完整执行链尚待真实客户端及机器人回合验证。

## 三项验收

1. **AI-friendly**：真实 MCP 客户端完成工具发现和调用；工具 schema、返回值和来源能供 GPT 使用，trace 串联检索、当前 plan 与执行回执。
2. **Cost-efficient**：冻结同任务、模型、预算和执行器的对照；记录端到端耗时、输入 / 输出 / 缓存 token、模型及控制调用次数，保留失败与重试成本。在效果不下降前提下，按事先确定的效率主指标判断收益。
3. **有效性**：真实回合取得原生 success / progress，保存轨迹和结果；成功率报告分母，任务完成度报告评分口径。工具返回成功或模型声称完成均不能代替原生判定。

最终任务、布局 / 种子、模型、预算、重复次数、对照配置与效率阈值尚待冻结；`stack_blocks` 是已有检索示例，当前不将其写成已确定的正式评测任务。
