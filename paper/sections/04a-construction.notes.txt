Agreed with formulation agent
- G=(V,E,A), with analogous P_t and X_t.
- Node is one phase instance. Object roles are typed arguments, never object nodes.
- Preconditions and mandatory dependencies are AND; incoming alternative transitions are OR. Precedence constrains only activated branches. Recovery is a guarded transition that additionally links a failed phase to its remedy.
- Predicate truth true/false/unknown is separate from evidence origin and annotation confidence.
- Historical and current event nodes carry observed outcomes; plan nodes specify intended effect/completion evidence. Rendering must never merge these statuses.

Construction-specific experiment requests
- Phase labels and boundary interval agreement on held-out annotated source episodes, plus evidence attribution accuracy and unsupported positive predicate rate. Human adjudication for annotation gold data only; no human oracle during deployment.
- Prefix replay: whether phase/guard labels can be assigned from observations available at decision time; report unknown decisions separately.
- Compare event-based segmentation with matched fixed windows, and compare subgraph extraction with and without dependency/recovery closure under the same evidence budget.
- Evaluate the same bank with graph and matched linearized records. Match evidence and approximate token/image budget so topology, not extra observations, causes differences.
- Track invalid graph records and annotation/adjudication time; dynamic representation needs construction cost measured.

Open integration decisions
- Root should state a short initial phase vocabulary (approach, grasp/contact, inspect/verify, transport, place/release, recovery; not mandatory sequence). Reobserve is an observation skill phase, not an unobservable mode.
- Need an explicit deployment predicate evaluator for RGB + proprioception: bounded supervisor visual checking is proposed, not an existing calibrated perception module. Indicate estimated evidence and report correctness against independent labels.
- Unknown guard path needs deterministic choice: perform a declared observation phase if available, otherwise hold/escalate. No observation strategy should appear from nowhere when the plan lacks a permitted one.
- Retrieval root should align closure budget: if closure exceeds budget, select another complete candidate or explicitly return no compatible evidence, rather than truncate the trigger or prerequisite.
- The graph closure includes required prerequisite/trigger records, not every temporal ancestor. Recursive dependency closure may grow; record size and budget rejection are measurable.
- Node temporal intervals are symbolic for plans; source times and coordinates should not become current geometric instructions.
