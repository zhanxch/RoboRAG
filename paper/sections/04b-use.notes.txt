Mechanism decisions made concrete:
- GPT receives a field/edge schema, capability skill signatures, an annotated example, and bounded checker feedback. Structured fields drive execution; explanations support inspection.
- P^- is a query skeleton, not a fixed template. Dual retrieval operates over complete graphs and phase-centered subgraphs with retained boundary prerequisites.
- Alignment score separates goal, roles, current/achievable/unknown/contradicted conditions, typed local topology, and recorded outcomes, with edit/context cost. Exact weights/thresholds are experimental hyperparameters, fixed from development tasks.
- Five edits: rebind roles, ground geometry, insert prerequisites, replace unsupported phases with declared supported equivalents, import bounded recovery. Capability filter allows only declared replacements; arbitrary imagined replacements are not admissible.
- Validation handles mandatory AND and alternative OR, branch priorities, prerequisite producers, resource constraints, finite retry budgets, and ordering. Structural validity does not imply physical feasibility/success.
- Supervisor authority is limited to approved phases, branches, observation/recovery, and bounded re-grounding. Planner controls role, topology, strategy, condition, and budget changes. Gateway rejects stale versions; local controller owns servo behavior.
- Receipt resolution and predicate evidence are separate: receipt acknowledgment never means completion. Benchmark oracle is excluded from control. Evaluation must state actual runtime predicate evaluators and their accuracy/calibration.
- Current execution X retains failed events; attempts have fresh IDs; plan revisions preserve unchanged IDs and record lineage. Only publish revised plan after in-flight execution resolves or cancellation is confirmed.
- Main bank frozen; current X available online; cross-episode graph/index update only in separate accumulation protocol.
