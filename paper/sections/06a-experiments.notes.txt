Important design choices:
1. No-retrieval cannot receive the same retrieved examples as retrieval. Shared source corpus means equal experimental data access; exact matched payloads are reserved for encoding/execution comparisons.
2. In the 2x2, retrieval changes selected evidence by definition. Candidate universe, available node information, payload schema, and packing ceilings are fixed; execution pairs share exact retrieved payloads within each retrieval condition. A fixed-candidate replay isolates execution. Do not simplify this to 'all four cells use identical evidence.'
3. A lossless text rendering retains graph information. It compares encoding or use, whereas removal of dependency/recovery/outcome records tests information. Do not describe linearization as deleting graph structure.
4. A smaller supervisor versus high-level-only is confounded by model capacity. The same-model constrained-supervisor condition is essential; control is kept identical. Realized later plans may diverge through observed outcomes even with identical initial plans and escalation policies.
5. Main success is judged externally. Method uses an observable verifier for control; native task oracle stays evaluator-only. Real-robot rubric, adjudication reliability, and whether reference evidence can resolve occluded outcomes need to be specified before data collection.
6. Final success is an intention-to-evaluate measure over all assigned trials. The recovery-only experiment uses a common perturbed state, not each method's own failures.
7. Numerical trial counts, minimum meaningful differences, simulator perturbation magnitudes, and effect tolerances must be fixed from development data before held-out runs. They are deliberately not invented in this design draft.
8. Annotation reference construction includes independent raters, pre-adjudication agreement and cost. For outcome uncertainty, a reference may itself be unknown; report unresolvable reference cases rather than force truth labels.
9. The sections assume supported skill libraries can be held fixed within a backend. They do not assume identical skill quality, physics, or outcomes across RoboDojo/LIBERO/real robot.
10. Parent should prioritize the graph factorial, composition/adaptation, construction quality, and hierarchy audit when scheduling experiments. Chronological accumulation and the full three-backend study can follow the frozen-bank core, without claiming completed MCP portability.
