回放与原始记录如何对应？

第 0 帧是初始观测；第 n 帧对应 commands.jsonl 第 n 条命令执行结束后的截图。播放帧之间只重复保存的截图，没有生成中间运动。原始 MP4 也仅含稀疏观测，编码帧率不等于连续采集率。

仿真时间 = 已执行动作步数 ÷ 25 Hz；回放时间是人为设置的阅读节奏。只读命令的仿真步数可能保持不变。最终成绩来自 RoboDojo 原生评分器，工具回执并不是任务成功判据。
